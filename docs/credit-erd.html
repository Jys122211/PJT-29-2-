[a] credit_loan_products 신용대출 상품

  • loan_product_id 상품 ID
  • product_name 상품이름
  • loan_limit 대출 최고금액(원)
  • max_discount_rate 최고 우대금리(%)
  • updated_at 업데이트 날짜
  • is_deleted N=판매중 / Y=판매종료(논리삭제)
  • last_batch_id 현재값을 만든 배치

[b] credit_loan_grade_rate 등급·기간별 금리

  • loan_credit_grade_rate_id 등급별 금리 ID
  • loan_product_id 신용대출 상품 ID
  • rate_period_months 금리변동주기 3 / 6 / 12개월
  • credit_grade 신용등급
  • base_rate 기본금리(%)
  • spread_rate 가산금리(%)
  • last_batch_id 현재값을 만든 배치

[c] credit_loan_preferential_condition_question 우대 질문

  • credit_loan_preferential_condition_question_id 우대조건 질문 ID
  • credit_loan_preferential_condition_question_name 우대조건 이름
  • credit_loan_preferential_condition_question_detail 우대조건 상세설명

[d] credit_loan_preferential_rate 상품·우대 연결

  • credit_loan_preferential_rate_id 우대금리 ID
  • loan_product_id 신용대출 상품 ID
  • credit_loan_preferential_condition_question_id 우대조건 질문 ID
  • discount_rate 우대금리(%)

[e] credit_loan_qualification_condition_question 자격 질문

  • qualification_condition_question_id 자격조건 질문 ID
  • question_text 신청 조건
  • crawl_source_key KB 페이지 원문에서 공백을 지운 값 · 기존 조건인지 판정할 때 사용

[f] credit_loan_qualification_condition 상품·자격 연결

  • qualification_condition_id 신용대출 자격조건 ID
  • loan_product_id 신용대출 상품 ID
  • credit_loan_qualification_condition_question_id 신용대출 자격조건 질문 ID

[g] credit_loan_products_history 상품 이력

  • products_history_id 상품 이력 ID
  • crawl_batch_id 배치 ID
  • loan_product_id 라이브 상품 ID
  • product_name 수집 당시 원본 상품명
  • product_name_key 정규화한 상품명
  • detail_url 실제로 수집에 성공한 상세 URL
  • loan_limit 대출 최고금액 · 파싱 실패 시 NULL
  • loan_limit_raw 한도 원문 텍스트 · 디버깅용
  • max_discount_rate 최고 우대금리(%)
  • source_state PRESENT=KB에 존재 / REMOVED=사라짐
  • collect_status OK / FAILED
  • failure_reason 수집 실패 원인
  • snapshot_hash 내용 SHA-256 · 무변경 배치 스킵 판정용

[h] credit_loan_grade_rate_history 등급별 금리 이력

  • grade_rate_history_id 등급별 금리 이력 ID
  • products_history_id 상품 이력 ID
  • rate_period_months 금리변동주기 3 / 6 / 12개월
  • credit_grade 신용등급 1 ~ 4
  • base_rate 기준금리(%)
  • spread_rate 가산금리(%)
  • rate_origin CRAWLED=사이트 원본 / DERIVED=공시 비율 환산
  • rate_type_raw 수집 당시 금리구분 원문 · 파싱 회귀 추적용

[i] crawling_batch_history 신용·전세 공용 배치 이력

  • crawl_batch_id 배치 ID
  • batch_uuid 외부 추적·로그 대조용 UUID
  • bank_name 수집 대상 은행
  • product_category CREDIT_LOAN / JEONSE_LOAN
  • status RUNNING / SUCCESS / PARTIAL / FAILED / REJECTED
  • started_at 수집 시작 시각
  • finished_at 수집 종료 시각
  • executed_by 실행 주체 · scheduler 또는 수동 실행 계정
  • finlife_disclosure_month 등급 환산에 사용한 공시월 YYYY-MM
  • target_count 수집 대상 상품 수
  • success_count 상세 수집 성공 수
  • failed_count 상세 수집 실패 수
  • applied_to_live_yn 라이브 반영 여부
  • warnings 수집 경고 원문
