[a] jeonse_product 전세대출 상품

  • product_id 상품 ID
  • product_name 상품이름
  • bank_name 취급 은행
  • max_loan_limit 대출 최고금액(원)
  • detail_url 상세 페이지 URL
  • collected_at 수집 시각
  • max_preferential_rate 최고 우대금리(%)
  • last_batch_id 현재값을 만든 배치
  • is_deleted N=판매중 / Y=판매종료(논리삭제)

[b] jeonse_rate_option 금리 옵션

  • rate_option_id 금리 옵션 ID
  • product_id 전세대출 상품 ID
  • rate_type 금리 유형
  • base_rate 기준금리(%)
  • spread_rate 가산금리(%)
  • last_batch_id 현재값을 만든 배치

[c] jeonse_preferential_item 우대 항목

  • preferential_item_id 우대 항목 ID
  • condition_name 우대조건 이름
  • condition_detail 우대조건 상세설명
  • preferential_rate 우대금리(%)
  • crawl_source_key KB 페이지 원문에서 공백을 지운 값 · 기존 조건인지 판정할 때 사용

[d] jeonse_preferential_condition 상품·우대 연결

  • condition_id 연결 ID
  • product_id 전세대출 상품 ID
  • preferential_item_id 우대 항목 ID

[e] jeonse_eligibility_question 자격 질문

  • eligibility_question_id 자격조건 질문 ID
  • question_text 신청 조건
  • crawl_source_key KB 페이지 원문에서 공백을 지운 값 · 기존 조건인지 판정할 때 사용

[f] jeonse_eligibility_condition 상품·자격 연결

  • eligibility_condition_id 연결 ID
  • product_id 전세대출 상품 ID
  • eligibility_question_id 자격조건 질문 ID

[g] jeonse_products_history 상품 이력

  • jeonse_products_history_id 상품 이력 ID
  • crawl_batch_id 배치 ID
  • jeonse_product_id 라이브 상품 ID
  • product_name 수집 당시 원본 상품명
  • product_name_key 정규화한 상품명
  • bank_name 취급 은행
  • detail_url 실제로 수집에 성공한 상세 URL
  • max_loan_limit 대출 최고금액 · 파싱 실패 시 NULL
  • max_loan_limit_raw 한도 원문 텍스트 · 디버깅용
  • max_preferential_rate 최고 우대금리(%)
  • source_state PRESENT=KB에 존재 / REMOVED=사라짐
  • collect_status OK / FAILED
  • failure_reason 수집 실패 원인
  • snapshot_hash 내용 SHA-256 · 무변경 배치 스킵 판정용

[h] jeonse_rate_option_history 금리 이력

  • jeonse_rate_option_history_id 금리 이력 ID
  • jeonse_products_history_id 상품 이력 ID
  • rate_type 금리 유형
  • base_rate 기준금리(%)
  • spread_rate 가산금리(%)

[i] credit_crawling_batch_history 신용·전세 공용 배치 이력

  • crawl_batch_id 배치 ID
  • batch_uuid 외부 추적·로그 대조용 UUID
  • bank_name 수집 대상 은행
  • product_category CREDIT_LOAN / JEONSE_LOAN
  • status RUNNING / SUCCESS / PARTIAL / FAILED / REJECTED
  • started_at 수집 시작 시각
  • finished_at 수집 종료 시각
  • executed_by 실행 주체 · scheduler 또는 수동 실행 계정
  • finlife_disclosure_month 등급 환산에 사용한 공시월 YYYY-MM
  • target_count 수집 대상 상품 수
  • success_count 상세 수집 성공 수
  • failed_count 상세 수집 실패 수
  • applied_to_live_yn 라이브 반영 여부
  • warnings 수집 경고 원문
